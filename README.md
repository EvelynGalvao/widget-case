MODULE & API REQUIREMENTS IN ZOHO CRM

To ensure proper integration of the widget, please verify that the module
and field API names are configured exactly as listed below:

Module API Name: Contacts

Field API Names (Contacts Module):

First Name                         -> First_Name

Last Name                          -> Last_Name

Email                              -> Email

Phone                              -> Phone

Mailing Address - City             -> Mailing_City

Mailing Address - Country / Region -> Mailing_Country

Mailing Address - State / Province -> Mailing_State

Mailing Address - Street Address   -> Mailing_Street

Mailing Address - Zip / Postal Code-> Mailing_Zip
